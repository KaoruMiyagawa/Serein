# 沉沦 · 第一版产品需求文档

## 1. 产品定位

沉沦是一个只服务于两个人的私人情侣空间。

核心关键词：

- 简洁
- 私密
- 柔和
- 无广告
- 无社区
- 无推荐内容
- 以手机端为主，兼容电脑浏览器

视觉方向：雾感暖白。

吉祥物：用户确认的 Q 版橘猫，后续用于 App 图标、首页陪伴、打卡反馈和桌宠。

## 2. 第一版功能范围

### 包含

1. 普通账号注册 / 登录
2. 手机号或邮箱注册
3. 创建情侣空间
4. 邀请码绑定另一半
5. 今日首页
6. 每日情侣打卡
7. 纪念日 / 倒计时
8. 回忆时间线
9. 留言
10. 基础个人和空间设置

### 暂不包含

- 微信登录
- QQ 登录
- 随机情侣任务
- 共同足迹
- 图片和照片
- AI 功能
- 社区、推荐、动态广场
- 积分、排行榜、连续打卡奖励
- 实时聊天和 WebSocket

## 3. 用户和情侣空间规则

- 一个用户第一版只能加入一个情侣空间。
- 一个情侣空间最多绑定两名用户。
- 创建空间时空间名称可以跳过。
- 创建空间后生成 6 位随机邀请码。
- 邀请码可以复制。
- 邀请码在绑定成功后失效。
- 绑定成功后双方进入同一个空间。
- 解除绑定需要双方确认。
- 解除绑定不立即删除历史数据。
- 解除绑定后，双方暂时不能继续访问共同内容，后续再决定数据保留策略。

## 4. 页面结构

### 4.1 登录页

内容：

- 沉沦名称
- 手机号或邮箱
- 密码
- 登录按钮
- 注册账号
- 忘记密码
- 微信 / QQ 登录位置暂时预留，不实现

主要状态：

- 默认状态
- 输入错误
- 账号或密码错误
- 登录中
- 网络错误

### 4.2 注册页

内容：

- 手机号或邮箱
- 设置密码
- 确认密码
- 注册按钮

注册成功后进入：

> 创建空间 / 输入邀请码

### 4.3 情侣绑定页

#### 创建空间

- 空间名称，可跳过
- 创建空间
- 我有邀请码

#### 等待绑定

- 6 位邀请码
- 复制邀请码
- 等待另一半加入

#### 输入邀请码

- 邀请码输入框
- 确认绑定
- 邀请码错误提示

#### 绑定成功

- 双方头像或昵称
- 绑定成功
- 进入今天

### 4.4 今日首页

首屏内容：


- 日期
- 吉祥物小尺寸陪伴
- 双方昵称 / 头像
- 今日打卡状态
- 去打卡按钮
- 最近纪念日
- 最近一条回忆

首页主操作只有一个：

> 去打卡

### 4.5 打卡页

内容：

- 日期
- 简短提示语
- 文字输入框，可为空
- 提交打卡

规则：

- 每天只能提交一次
- 打卡内容允许修改
- 双方都完成后显示共同完成
- 对方未完成时显示等待状态

### 4.6 纪念日页

内容：

- 最近纪念日倒计时
- 纪念日列表
- 添加纪念日
- 编辑纪念日
- 删除纪念日

纪念日字段：

- 名称
- 日期
- 是否每年重复

预设类型：

- 相识纪念日
- 在一起纪念日
- 生日
- 自定义

### 4.7 回忆页

内容：

- 月份筛选
- 垂直时间线
- 打卡记录
- 留言记录
- 双方完成状态

回忆由以下内容组成：

- 每日打卡
- 每日留言
- 纪念日记录

第一版以文字为主，不做图片墙。

### 4.8 我的 / 设置页

内容：

- 我的昵称
- 头像占位
- 情侣空间信息
- 邀请码
- 解除绑定
- 深色模式
- 退出登录

## 5. 底部导航

手机端固定 4 个入口：

1. 今日
2. 回忆
3. 纪念日
4. 我的

打卡不是底部导航入口，而是今日页的主要按钮。

## 6. 页面跳转流程

```text
未登录
  ├─ 登录成功
  └─ 注册成功
          ↓
    创建空间 / 输入邀请码
          ├─ 创建空间
          │    ↓
          │  等待另一半绑定
          │    ↓
          │  绑定成功
          │
          └─ 输入邀请码
               ↓
             绑定成功
               ↓
             今日首页
               ├─ 今日打卡
               ├─ 纪念日
               ├─ 回忆
               └─ 我的
```

## 7. 今日打卡流程

```text
今日首页
  ↓
点击“去打卡”
  ↓
填写内容，可为空
  ↓
提交打卡
  ├─ 对方未完成：显示“等待对方”
  └─ 对方已完成：显示“今日共同完成”
```

## 8. 第一版视觉规则

- 页面背景：暖白
- 卡片：白色
- 主按钮：柔和陶土色
- 辅助色：浅鼠尾草绿、浅杏色
- 大卡片圆角：20–24px
- 输入框圆角：12px
- 阴影：轻微或使用细边框代替
- 吉祥物：小尺寸、低频出现、不遮挡主要内容
- 动画：淡入、轻微缩放、轻微跳动

## 9. 吉祥物使用规则

第一版只作为视觉和反馈元素使用，不影响核心功能。

出现位置：

- 登录页小图形
- 首页顶部或空白区域
- 打卡成功页面
- 桌面端可选桌宠

建议动作：

- 待机：轻微呼吸
- 登录成功：眨眼
- 打卡成功：轻轻跳一下
- 对方完成打卡：挥爪
- 长时间未操作：睡觉

不做：

- 自动弹窗
- 频繁说话
- 遮挡内容
- 强制互动

## 10. 后续技术设计顺序

产品规则确认后，依次设计：

1. 数据库表结构
2. REST API 接口
3. 前端路由和页面状态
4. React 项目结构
5. FastAPI 项目结构
6. MySQL 初始化
7. 登录注册开发
8. 情侣绑定开发
9. 首页和打卡开发
10. 纪念日、回忆和设置开发

微信和 QQ 登录放在第一版基础流程稳定之后接入。
